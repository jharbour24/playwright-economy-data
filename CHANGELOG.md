# Changelog

Each release is one commit in this repository, tagged with its version.

## v2.0 (2026-10-16)
Adds 54 aggregate tables: the afterlife of new plays and who licenses it, merger concentration, the school and amateur
market, licence fees, newcomer and house-writer replications on the corrected build, Equity LORT work weeks, TCG
subscriber windows, and a playwright income model with its assumptions (`config/r3_assumptions.yaml`). Adds
ESSAY_NUMBERS.md. The v1.0 tables are unchanged. History was reset to a single commit for this release.

## v1.0 (2026-10-07)
First public release: 37 corrected summary tables (aggregates only), README and data dictionary.
